# 회독노트 · 2027.03.27 국가직

공시생 진도 관리 웹앱. 단일 HTML 파일(`index.html`)로 동작하며, 설치 없이 브라우저에서 바로 열립니다.

## 쓰는 법

- 라이브: <https://jinha4826-ship-it.github.io/-/>
- 저장소 이름을 바꾸면 GitHub Pages 주소도 그 이름을 따라 함께 바뀝니다.
- iPhone에서는 Safari로 열고 **공유 → 홈 화면에 추가**를 누르면 앱처럼 전체 화면으로 실행됩니다.

## 기능

- **진도**: 과목별 인강·단원·쪽·모의고사 회차 단위로 전체 분량 대비 진행률 관리
- **복습**: 1·3·7·14일 간격 복습 일정 자동 계산과 오늘 복습 목록
- **목표 시험 설정**: 시험 이름과 날짜(D-day) 지정
- **기록 백업·복원**: JSON 파일로 내보내기·가져오기 (브라우저 캐시가 지워져도 복구 가능)

## 저장 방식

모든 기록은 브라우저 `localStorage`(키: `hoedok_note_2027_v1`)에만 저장되고 서버로 전송되지 않습니다. 기기를 바꾸거나 캐시를 지울 때는 미리 **추가·백업 → 내보내기**로 JSON을 저장해 두세요.
